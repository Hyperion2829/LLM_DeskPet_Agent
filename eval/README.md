这是我让ai生成的说明，我修改了一部分，现在基本没有问题，想更改一些配置的话照里面说的做即可。
有些文件可能没必要分开，但试了下ai似乎同时生成做两件事情的代码有点笨，所以尽可能让一个代码只做一件事。
评测脚本主要考察以下内容（除最后一项外都会返回正确率，最后一项则是1-5打分（范围可以调），总分给了个加在一起的权重，要不要随意，最后的报告里也会给出分别各自的）：

| `json_valid` | JSON 是否合法
| `fields_valid` | 每条回复是否包含 `text` 和 `action`
| `action_valid` | action 是否在合法动作集合中
| `action_match` | action 是否与给出的答案一致
| `length_valid` | text 是否超过长度限制
| `forbidden_phrase_free` | 是否出现禁用表达（这个禁用表达包括什么写在里面了，我不确定全不全
| `judge_persona_score` | 人格一致性评分，这个是启用强模型的

其中最重要的文件是 eval_config.yaml 。里面包含上述所有可以调节的东西，包括是否开启强模型评价（当然了这个我们肯定是要的）。其他文件有的是调用强模型评价的配置，有的是评测不同指标时的函数构造， metrics.py 文件会把所有汇总的结果写成一个md和json文件。而 run_eval.py 则是主函数，依照介绍里写的在终端启动这个即可。

eval_config.yaml 里的系统提示词已经改完了，鉴于其有点长，我单独把它存在了shu_system_prompt.txt里。具体里面有啥其他的能调注释也都写出来了。eval_cases.jsonl文件是我们的评测集（夏岩给的1k条），为了读取方便把它变成这种格式了。
